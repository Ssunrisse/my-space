## ✨ Meet My Space

Productivity isn't about doing more all the time. It's about making room for what matters.

**My Space** brings planning, concentration, and personal progress together in a customizable workspace. Whether you're studying for an exam, managing a project, or building a new routine, it helps you stay organized without losing your sense of calm.

## 🌙 Explore the workspace

| Feature | What you can do |
| --- | --- |
| **Personal Dashboard** | Organize widgets, view your calendar, and see what matters today. |
| **Task Management** | Plan tasks with dates, priorities, categories, and filters. |
| **Focus Mode** | Use a Pomodoro timer, track completed sessions, and take intentional breaks. |
| **Ambient Studio** | Mix environmental sounds and save your favorite soundscapes. |
| **Notes & Journal** | Write and organize notes in folders with an editor and search. |
| **Habit Tracker** | Track daily routines, streaks, and consistency. |
| **Unified Statistics** | Review task progress, habits, and focus activity. |
| **Themes** | Choose Midnight Amethyst, Crimson Ronin, Pearl Dawn, or Dark Monochrome. |
| **Backup & Restore** | Export and import your personal data. |

## 🎨 Make it yours

Four distinct themes. Customizable dashboard widgets. Relaxing ambient soundscapes. Your workspace should feel like **your** space.

## 🚧 Development status

My Space is under active development. Its existing features are being prepared for a public web release.

**Accounts and cloud sync are in progress.** Until account isolation and synchronization have been thoroughly tested, data may remain on the individual browser or require manual backup and restore. Do not rely on the app as the only copy of important information.

## 🛠️ Built with

- HTML, CSS, and vanilla JavaScript
- Browser storage: localStorage and IndexedDB
- Supabase for planned authentication and cloud synchronization
- Git and GitHub for version control

## 🔐 Privacy and data

My Space is being designed so each account can access only its own personal data. Before public registration opens, authentication, database access policies, backup and recovery, and cross-account isolation must be tested.

**Never put secret API keys, passwords, or private service credentials in client-side code.**
