# ✨ My Space

**A modern and customizable personal productivity dashboard built with HTML, CSS, and vanilla JavaScript.**

My Space is my first web development project, created as a hands-on learning experience to practice front-end development, JavaScript fundamentals, and Git version control.

## 🚀 Features

- 🕒 **Live Clock** — Displays the current time and updates automatically.
- 📅 **Current Date** — Shows the current date in a readable format.
- ✅ **Task Manager** — Add, complete, and delete daily tasks.
- 👋 **Personalized Greetings** — Displays a greeting based on the time of day and your saved name.
- 🌙 **Light & Dark Mode** — Switch between two themes.
- 💾 **Local Storage** — Saves tasks and preferences in your browser.
- 📱 **Responsive Layout** — Includes styling adjustments for smaller screens.

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic content.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript** — Interactivity, DOM manipulation, and local storage.
- **Git & GitHub** — Version control and project hosting.

## 💻 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Ssunrisse/my-space.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

For more consistent browser storage behavior, running the project through a local development server is recommended.
